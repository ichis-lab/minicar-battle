# Five Sensor Reader - シンプル状態ベース制御

## 概要

5つのVL53L1X ToFセンサーを使用した自動運転ミニカーの壁追従制御システム。
**シンプルな状態ベース制御**により、直感的で調整しやすい制御を実現。

### 特徴

- **VL53L1X対応**: 最大4mの測定範囲
- **状態ベース制御**: PID不要、閾値判定のみのシンプルな制御
- **右壁追従**: 基本は右壁との距離を一定に保つ
- **自動コーナリング**: 正面に壁を検知したら開いている方向へ曲がる

## 制御アルゴリズム

### 状態遷移図

```
                    ┌─────────────────┐
                    │  側壁接近回避    │ ← 常時チェック（最優先）
                    │ S0 or S4 < 200mm│
                    └────────┬────────┘
                             │
         ┌───────────────────┼───────────────────┐
         │                   │                   │
         ▼                   ▼                   ▼
┌─────────────┐      ┌─────────────┐      ┌─────────────┐
│  緊急回避   │      │ コーナリング │      │   直進      │
│ S2 < 300mm │ ←──  │ S2 < 800mm  │ ←──  │ S2 > 800mm │
│ 減速+最大舵│      │ 方向判定+舵 │      │ 右壁追従   │
└─────────────┘      └─────────────┘      └─────────────┘
```

### 制御モード

#### MODE_STRAIGHT（直進モード）

**条件**: 正面センサー(S2) > 800mm

**動作**: 右壁(S4)との距離を目標値（600mm）に保つ

```
右壁 < 450mm  → 左へ 8°
右壁 > 750mm  → 右へ 5°
それ以外      → 直進
```

#### MODE_CORNER（コーナリングモード）

**条件**: 正面センサー(S2) < 800mm

**動作**: 左右どちらが開いているか判定し、開いている方向へ22°ステアリング

#### MODE_EMERGENCY（緊急回避モード）

**条件**: 正面センサー(S2) < 300mm

**動作**: 減速 + 最大ステアリング（30°）で回避

#### MODE_SIDE_AVOID（側壁回避モード）

**条件**: S0 or S4 < 200mm（常時チェック、最優先）

**動作**: 壁から離れる方向へ20°ステアリング

## 使用方法

### 必要なライブラリ

1. **VL53L1X** (Pololu) - Arduino IDEのライブラリマネージャーで「VL53L1X pololu」を検索
2. **Servo** (Arduino標準ライブラリ)

### 書き込み手順

1. Arduino IDEで `five_sensor_reader.ino` を開く
2. `Config.h` で `DEBUG_MODE` を設定
   - `true`: シリアル出力あり、PWM出力なし
   - `false`: シリアル出力なし、PWM出力あり
3. Arduino Nano R4に書き込み
4. シリアルモニター（115200bps）で動作確認

## チューニングガイド

### 右壁追従の調整

```
TARGET_WALL_DISTANCE: 右壁との目標距離
  - 狭いコース: 400〜500mm
  - 広いコース: 600〜800mm

WALL_TOLERANCE: 許容範囲
  - 大きい値: ふらつきが少ない、反応が鈍い
  - 小さい値: 反応が速い、ふらつきやすい
```

### コーナリングの調整

```
CORNER_THRESHOLD: コーナリング開始距離
  - 大きい値: 早めにコーナリング開始
  - 小さい値: ギリギリまで直進

CORNER_ANGLE: コーナリング時のステアリング角度
  - 大きい値: 急カーブ
  - 小さい値: 緩やかなカーブ
```

### 速度の調整

```
BASE_SPEED_PULSE: 基本速度（ms）
  - 1.5: 停止
  - 1.45: 低速
  - 1.4: 中速
  - 1.35以下: 高速（注意）
```

## 設計思想

### なぜシンプル状態ベース制御か

**従来のPID制御の問題**:
- パラメータ調整が難しい
- 壁角度計算の符号が複雑
- モード切り替え時の不連続性

**シンプル制御のメリット**:
- 閾値判定のみで直感的
- 各モードの動作が明確
- パラメータが独立していて調整しやすい
- デバッグが容易（モード名が表示される）

### 右壁追従を選んだ理由

- 一般的なRCコースは右回り
- 右壁を基準にすることで一貫した走行ラインを維持
- 左壁追従に変更する場合はS4→S0に変更するだけ
