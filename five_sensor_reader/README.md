# Five Sensor Reader - 角度ベース統一PID制御システム

## 概要

5つのVL53L1X ToFセンサーを使用した自動運転ミニカーの壁追従制御システム。
**角度ベース統一PID制御**により、モード切り替え時の不安定さを解消。

### 特徴

- **VL53L1X対応**: 最大4mの測定範囲（従来のVL53L0Xは2m）
- **統一PID**: 全モードで同じPIDを使用、I項・D項が常に蓄積
- **角度ベース入力**: 距離差も角度に変換してスケールを統一

## 制御アーキテクチャ

### 角度ベース統一制御

従来の2つのPID（距離用・角度用）を**1つのPIDに統合**。
全モードでPID入力を「角度（deg）」に統一することで、モード切り替え時の不連続性を解消。

```
┌─────────────────────────────────────────────────────────────┐
│                      入力の統一                              │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  両壁モード:                                                  │
│    error = (left_angle + right_angle) / 2                   │
│          + (right_dist - left_dist) × DISTANCE_TO_ANGLE_GAIN │
│                                                              │
│  片壁モード:                                                  │
│    error = wall_angle                                        │
│                                                              │
│  壁なし:                                                     │
│    steering = 0（直進）                                      │
│                                                              │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  全て同じPIDで計算 → リセットなし → I項・D項が蓄積           │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 処理フロー（60ms = 16.7Hz）

```
Phase 1: センサーデータ取得
    └─▶ sensorReader.readAll()
         5つのVL53L1Xから距離・信号強度・環境光を取得

Phase 2: 緊急停止チェック
    └─▶ 前方センサー < 200mm → 停止

Phase 3: 壁検出
    └─▶ wallDetector.detect()
         左右の壁の垂直距離・角度を計算

Phase 4: ステアリング計算
    └─▶ steeringController.calculate()
         角度ベース統一PIDで操舵角を算出

Phase 5: アクチュエーター制御
    └─▶ actuator.setSteering() / setSpeed()
```

## 制御モード

### MODE_BOTH_WALLS（両壁検出）

```
目標: コース中央を走行

     左壁                     右壁
      │                        │
      │←─ left_angle ─→車←─ right_angle ─→│
      │                        │

中央角度 = (left_angle + right_angle) / 2
距離補正 = (right_dist - left_dist) × 0.01

error = 中央角度 + 距離補正
```

### MODE_LEFT_WALL / MODE_RIGHT_WALL（片壁検出）

```
目標: 壁と平行に走行

     壁
      │
      │  ╲ wall_angle > 0 → 壁に向かっている
      │   ╲
      │    車 ───→ 進行方向
      │

error = wall_angle

＋ 安全距離制約:
  距離 < 300mm → 離れる方向に補正
```

### MODE_NO_WALLS（壁なし）

```
steering = 0（直進）
```

## 壁検出アルゴリズム

### 壁までの垂直距離計算

```
2つのセンサーで検出した点 P1(x1,y1), P2(x2,y2) から
壁の直線を推定し、原点（車体）からの垂直距離を算出

        P1 ●
            ╲
             ╲  壁の直線
              ╲
               ● P2

        車体 ○────────┤ 垂直距離 d

公式: d = |x1×y2 - x2×y1| / √((x2-x1)² + (y2-y1)²)
```

### 壁角度計算

```
壁の直線が車体正面方向（y軸）となす角度

angle = atan2(dx, dy)

  angle > 0: 壁に向かっている（前方で近づく）
  angle < 0: 壁から離れている（前方で遠ざかる）
  angle = 0: 壁と平行
```

## 使用方法

### 必要なライブラリ

1. **VL53L1X** (Pololu) - Arduino IDEのライブラリマネージャーで「VL53L1X pololu」を検索
2. **Servo** (Arduino標準ライブラリ)

### 書き込み手順

1. Arduino IDEで `five_sensor_reader.ino` を開く
2. `Config.h` で `DEBUG_MODE` を設定
   - `true`: シリアル出力あり、PWM出力なし
   - `false`: シリアル出力なし、PWM出力あり
3. Arduino Nano R4に書き込み
4. シリアルモニター（115200bps）で動作確認

## チューニングガイド

### PIDゲイン調整

```
1. STEERING_KP のみで開始 (Ki=0, Kd=0)
   - 振動が始まるまで Kp を増加
   - その値の 50-60% を使用
   - 目安: 壁角度5°で約4°のステアリング

2. STEERING_KD を追加
   - オーバーシュートが減少するまで増加
   - 応答が遅くなりすぎない程度に

3. STEERING_KI を追加
   - 定常偏差がなくなるまで増加
   - ハンチング（小刻みな振動）に注意
```

### 距離→角度変換ゲイン

```
DISTANCE_TO_ANGLE_GAIN = 0.01 の意味:
  - 左右距離差 100mm → 1deg の補正
  - 距離差 300mm → 3deg の補正

コース幅に応じて調整:
  - 狭いコース: ゲインを上げる（0.02〜0.03）
  - 広いコース: ゲインを下げる（0.005〜0.01）
```

## 設計思想

### なぜ角度ベース統一制御か

**従来の問題**:
- 2つのPID（距離用・角度用）をモードごとに切り替え
- モード切り替え時にPIDリセット → I項・D項が蓄積されない
- コーナーでモードがバタつき、実質P制御になっていた

**解決策**:
- 全モードで「角度（deg）」を入力としてスケールを統一
- 1つのPIDで一貫した制御
- モード切り替え時にリセットしない → I項・D項が常に蓄積

### 安全距離制約の設計

安全距離制約はPIDの**外側**で加算される:

```cpp
steering = _pid.compute(0.0, error);

// PIDの後に加算
if (distance < MIN_SAFE_DISTANCE) {
    steering += correction;
}
```

**理由**:
- PIDは「壁と平行」を維持する役割
- 安全制約は「衝突回避」の役割
- 役割を分離することで調整が容易に

**注意点**:
- PIDの積分項はこの補正を「知らない」
- 長時間の安全制約発動で積分がずれる可能性あり
- 将来的にはアンチワインドアップとの連携を検討
