# Five Sensor Reader - PID制御壁追従システム

## 概要

5つのVL53L0X ToFセンサーを使用した自動運転ミニカーの壁追従制御システム。
PID制御により、オーバーシュート抑制、定常偏差解消、急変化への追従を実現。

```
        前方 (Index 2: 0°)
              │

          \   │   /
           \  │  /
-70°        \ │ /        +70°
(Idx 0)      \│/      (Idx 4)
           [車体]
```

## 処理フロー

### メインループ（40ms = 25Hz）

```
┌─────────────────────────────────────────────────────────────┐
│ Phase 1: センサーデータ取得                                   │
│   sensorReader.readAll()                                     │
│   → 5つのセンサーから距離データを取得                         │
└─────────────────────────────────────────────────────────────┘
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ Phase 2: 緊急停止チェック                                     │
│   前方センサー(Index 2) < 200mm                               │
│   → true: ステアリング中央 + モーター停止                     │
└─────────────────────────────────────────────────────────────┘
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ Phase 3: 壁検出                                              │
│   wallDetector.detect(sensorData)                            │
│   → 左右の壁の有無、垂直距離、角度を計算                      │
│                                                              │
│   計算方法:                                                   │
│   - 2つのセンサー点から壁の直線を推定                         │
│   - 直線と原点（車体位置）の垂直距離を算出                    │
│   - 直線の傾きから壁角度を算出                                │
└─────────────────────────────────────────────────────────────┘
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ Phase 4: 制御モード判定                                       │
│                                                              │
│   ┌─────────────┬────────────────────────────────────────┐  │
│   │ モード       │ 条件                                   │  │
│   ├─────────────┼────────────────────────────────────────┤  │
│   │ BOTH_WALLS  │ 左右両方の壁を検出                      │  │
│   │ LEFT_WALL   │ 左壁のみ検出                           │  │
│   │ RIGHT_WALL  │ 右壁のみ検出                           │  │
│   │ NO_WALLS    │ 壁なし                                 │  │
│   └─────────────┴────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ Phase 5: ステアリング角度計算（PID制御）                      │
│                                                              │
│   【両壁モード】centeringPID                                  │
│     目標: 左右壁からの距離差 = 0（中央走行）                  │
│     誤差 = 右壁距離 - 左壁距離                                │
│     → 距離差に応じてステアリング角度を算出                   │
│                                                              │
│   【片壁モード】anglePID                                      │
│     目標: 壁角度 = 0°（壁と平行に走行）                       │
│     誤差 = 壁の角度                                          │
│     → 壁と平行になるようステアリング角度を算出               │
│                                                              │
│     ＋ 安全距離制約:                                         │
│       壁距離 < 150mm の場合、離れる方向に補正                 │
│                                                              │
│   【壁なし】直進（ステアリング = 0）                          │
└─────────────────────────────────────────────────────────────┘
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ Phase 6: アクチュエーター制御                                 │
│   actuator.setSteering(steering_angle)                       │
│   actuator.setSpeed(BASE_SPEED_PULSE)                        │
└─────────────────────────────────────────────────────────────┘
```

## 制御モード詳細

### MODE_BOTH_WALLS（両壁検出）

```
目標: コース中央を走行

     左壁                     右壁
      │                        │
      │   ←── 左距離 ──→車←── 右距離 ──→   │
      │                        │

誤差 = 右距離 - 左距離
  正（右が遠い）→ 右にステアリング
  負（左が遠い）→ 左にステアリング

PID: centeringPID.compute(0, -(右距離 - 左距離))
```

### MODE_LEFT_WALL / MODE_RIGHT_WALL（片壁検出）

```
目標: 壁と平行に走行（近づきすぎない）

     壁
      │
      │  ╲ 壁角度 > 0 → 壁に向かっている
      │   ╲
      │    車 ───→ 進行方向
      │

1. 角度PIDで壁と平行を維持
   PID: anglePID.compute(0, 壁角度)

2. 安全距離制約（150mm以下で発動）
   壁が近すぎる → 離れる方向にステアリング補正
```

### MODE_NO_WALLS（壁なし）

```
直進を維持（ステアリング = 0°）
将来の加速制御に対応しやすい設計
```

## PIDコントローラー

### 構造

```cpp
PIDController {
    PIDGains   { Kp, Ki, Kd }           // ゲイン
    PIDState   { prev_error, integral }  // 状態
    PIDConfig  { output_min/max, integral_min/max, deadband }  // 設定
}
```

### 機能

| 機能 | 説明 |
|------|------|
| アンチワインドアップ | 積分値の蓄積を制限、急変時の暴走防止 |
| 不感帯 | 微小誤差での振動防止 |
| 微分フィルタ | センサーノイズの増幅抑制 |
| モード切替リセット | 制御モード変更時に積分値をリセット |

### 微分フィルタ

```
センサーノイズが微分項で増幅されることを防止

filtered = α × 今回の微分値 + (1-α) × 前回のフィルタ値

α（DERIVATIVE_FILTER_ALPHA）:
  0に近い → フィルタ強（応答遅い、ノイズ除去強）
  1に近い → フィルタ弱（応答速い、ノイズ残る）
```

## 壁検出アルゴリズム

### 壁までの垂直距離計算

```
2つのセンサーで検出した点 P1(x1,y1), P2(x2,y2) から
壁の直線を推定し、原点（車体）からの垂直距離を算出

        P1 ●
            ╲
             ╲  壁の直線
              ╲
               ● P2

        車体 ○────────┤ 垂直距離 d

公式: d = |x1×y2 - x2×y1| / √((x2-x1)² + (y2-y1)²)
```

### 壁角度計算

```
壁の直線が車体正面方向（y軸）となす角度

angle = atan2(dx, dy)

  angle > 0: 壁に向かっている（前方で近づく）
  angle < 0: 壁から離れている（前方で遠ざかる）
  angle = 0: 壁と平行
```

## チューニングガイド

### 両壁モード（距離PID）

```
1. STEERING_KP のみで開始 (Ki=0, Kd=0)
   - 振動が始まるまで Kp を増加
   - その値の 50-60% を使用

2. STEERING_KD を追加
   - オーバーシュートが減少するまで増加
   - 応答が遅くなりすぎない程度に

3. STEERING_KI を追加
   - 定常偏差がなくなるまで増加
   - ハンチングに注意
```

### 片壁モード（角度PID）

```
1. ANGLE_KP で壁と平行を維持できるか確認
   - 壁角度10°で約5°のステアリングが目安

2. ANGLE_KD でオーバーシュート抑制
   - 振動が出たら増加

3. MIN_SAFE_DISTANCE で安全距離を調整
   - 150mmで壁接触しないか確認

4. DISTANCE_AVOID_GAIN で回避強度を調整
   - 強すぎると振動、弱すぎると接触
```

## 変更履歴

### 2024-12-22: 片壁モード角度制御化 + 各種改善

#### 制御ロジックの変更

| 項目 | 変更前 | 変更後 |
|------|--------|--------|
| 片壁モード | 距離PID（壁から400mm維持） | 角度PID（壁と平行維持）+ 安全距離制約 |
| 壁距離計算 | 2点の平均距離（不正確） | 直線と原点の垂直距離（正確） |
| 微分項 | フィルタなし | ローパスフィルタ付き |

#### 削除したパラメータ（8個）

- `SENSOR_ERROR_VALUE`, `SENSOR_TIMING_BUDGET`（未使用）
- `SPEED_KP`, `MIN_SPEED_PULSE`, `MAX_SPEED_PULSE`, `CORNER_SPEED_PULSE`（未使用）
- `TARGET_LEFT_DISTANCE`（片壁モード変更により不要）
- `MIN_LEFT_DISTANCE`（`MIN_SAFE_DISTANCE`に統合）

#### 追加したパラメータ（6個）

| パラメータ | 値 | 用途 |
|-----------|-----|------|
| `ANGLE_KP` | 0.5 | 角度PID比例ゲイン |
| `ANGLE_KI` | 0.0 | 角度PID積分ゲイン |
| `ANGLE_KD` | 0.1 | 角度PID微分ゲイン |
| `MIN_SAFE_DISTANCE` | 150 | 最低安全距離（mm）左右共通 |
| `DISTANCE_AVOID_GAIN` | 0.15 | 距離制約ゲイン |
| `DERIVATIVE_FILTER_ALPHA` | 0.3 | 微分フィルタ係数 |

#### インターフェース変更

| クラス | 変更内容 |
|--------|----------|
| `PIDController` | `setFilterAlpha()`追加、`PIDState`に`filtered_derivative`追加 |
| `SteeringController` | `wallFollowPID`→`anglePID`に変更、`calculate()`から`sensorData`引数削除 |

#### 設計思想

- **片壁時は無理に距離を維持しない**: 壁と平行に走り、近すぎる場合のみ離れる
- **直進を優先**: 壁なし時は素直に直進（将来の加速制御に対応）
- **安全距離は左右共通**: 150mmを下回ったら離れる方向に補正
